**`/etc/hosts`** is used when you know both the **IP address** and the **hostname/domain** of a target. It manually maps the hostname to the IP, allowing your machine to resolve it without DNS. This is often required because many web servers host multiple websites on the same IP (virtual hosts) and only serve the correct site when you access it using the expected hostname, not the IP directly.

[IppSec - Search](https://ippsec.rocks/?#) to learn anything by a click and video streaming.

Web shell = Remote CMD/Bash/PowerShell accessed through a web browser. A web shell **does not magically make you Administrator/root**. It runs commands **as the web server's user** (e.g., `www-data`, `apache`, or an IIS application pool account). You can execute anything **that user** is allowed to execute.
