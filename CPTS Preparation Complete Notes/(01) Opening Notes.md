The first and foremost rule of anything, specially in cybersecurity is "Learning by doing". While doing Pentest for an organization, must make sure to keep it **in the "Scope"** and signed by both parties. Before going for the job path in this sector, this whole process requires a solid base of,

		1. Linux and Windows fundamentals
		2. Networking
		3. Web Applications
		4. Web Requests
		5. JavaScript Deobfuscation
		6. Active Directory
		
You don't need to be a pro or have an alien brain to memorize this all at first. As I have previously said, these need be learnt by more and more practices. Time, patience, and personal commitment all play a significant role here..

Penetration process includes:

1. **Pre Engagement** : where the main commitments, tasks, scope, limitations, and related agreements are documented in writing. 

2.  **Information Gathering /Reconnaissance :** We need to gather as much as information possible to get to the next step. Network Enumeration. Footprinting, Web information, OSINT etc are required here. Before attempting to exploit anything, we should have completed thorough information gathering, keeping detailed notes along the way.

3. **Scanning and Enumeration:** This step creates a detailed map of the target, revealing potential entry points for further exploration. It is also where the tester touches the target systems.

4. **Vulnerability Assessment:** This is where we use the information found to identify potential weaknesses. The information we gather in advance will influence the results of the `Exploitation` stage. '

5. **Exploitation:** Now exploit through the weakness! 

6. **Post-Exploitation:** where we escalate privileges on the target system. This assumes that we are already on the target system and can interact with it. **Lateral Movement** is where we move from the already exploited system through the network and attack other systems.

7. **Reporting**
