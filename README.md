# Cybersecurity Learning Journal

This repository documents my learning journey in cybersecurity, CTFs, open source contributions, and technical workflow.

I created this repo to keep honest notes about what I am learning, including:

* what I tried
* what confused me
* what worked
* what failed
* what I learned from the process


## Why I made this

As a cybersecurity student, I wanted one place to document my progress in a structured and honest way. Instead of only showing final polished work, I also want to record the debugging, mistakes, and lessons behind it.
